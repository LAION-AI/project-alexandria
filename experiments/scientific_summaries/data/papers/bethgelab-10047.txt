Title: GUIDEMOL: a Python graphical user interface for molecular descriptors based on RDKit
Authors: Joao Aires (NOVA School of Science and Technology)

Abstract:
GUIDEMOL is a Python computer program based on the RDKit software to process molecular structures and calculate molecular descriptors with a graphical user interface using the tkinter package. It can calculate descriptors already implemented in RDKit as well as grid representations of 3D molecular structures using the electrostatic potential or voxels. The GUIDEMOL app provides an easy access to RDKit tools for chemoinformatics users with no programming skills and can be adapted to calculate other descriptors or to trigger other procedures. A CLI is also provided for the calculation of grid representations. The source code is available at https://github.com/jairesdesousa/guidemol


## Introduction
Molecular descriptors are at the core of the QSPR/QSAR methodology, 1 which is used by a range of scientists from different areas and with varying levels of computer skills. This is also a main area of chemoinformatics, which is gradually permeating the curricula of chemistry, biology and material science degrees; software for teaching is thus required. Several computer programs are currently available to calculate molecular descriptors on different platforms.
The open-source Chemistry Development Kit (CDK) 2 platform is a collection of Java libraries for chemoinformatics applications, also including the calculation of molecular descriptors. Examples of graphical user interfaces (GUI) to calculate CDK-based molecular descriptors are the PaDEL software 3 and the CDK Descriptor Calculator GUI by Guha. 4 The BlueDesc 5 calculator is a command-line tool that converts an MDL SDFile into ARFF and LIBSVM formats with up to 174 descriptors using CDK and JOELib2. Tetko coordinated the implementation of thousands of descriptors from different chemoinformatics groups and packages in the OCHEM free web service, 6 which is also a portal for the training of QSPR models. ChemDes is another free web service that integrates several available packages to calculate 3679 molecular descriptors and 59 types of molecular fingerprints. 7 Proprietary software for the processing of molecular structures often include the ability to calculate molecular descriptors; examples are MOE, 8 VolSurf+, 9 CORINA Symphony, 10 ChemAxon Calculator Plugins, 11 and alvaDesc. 12 The Python open-source RDKit software 13 has implemented a wide range of chemoinformatics tools, including the calculation of molecular descriptors, and is currently much used in machine learning projects. The Mordred software 14 is a Python package designed to calculate molecular descriptors, some with RDKit wrappers, others with original implementations; it is provided for command-line use or as a web application.
Additionally, the Python programming language 15 enables the easy development of GUIs, namely based on tkinter, 16 which is the standard Python interface to the Tcl/Tk GUI toolkit. Tk/Tcl is an integral part of Python and the tkinter package is usually bundled with Python. It has been used to develop GUIs of chemoinformatics software based on RDKit. For example, Shi and Borchardt 17 combined RDKit and the tkinter module to write JRgui, a GUI program to calculate Joback and Reid group contribution molecular descriptors. The GUIDEMOL application presented in this Note relies on tkinter to build a GUI for the calculation of molecular descriptors with RDKit, as well as grid representations of 3D molecular structures. It was developed as a minimalist interface to routine chemoinformatics tasks and the calculation of well-established descriptors. The source code is available at https://github.com/jairesdesousa/guidemol under the three-clause Berkeley Software Distribution (BSD) license, which allows both commercial and non-commercial use, and can be very easily extended for the deployment of other molecular descriptors or as a template for GUIs to other chemoinformatics tasks.
Beyond RDKit descriptors, GUIDEMOL implements direct representations of 3D molecular structures. These types of representations have recently gained attention for their processing by complex artificial intelligence algorithms with larger data sets. The representation of molecules in 3D grids of voxels encoding their atoms has been used to train deep learning neural networks. 18, 19, 20, 21 Electrostatic potentials generated by point charges localized at the atom centers -another way of representing the 3D structure of molecules -has long since been used to establish relationships with molecular properties, namely in 3D-QSAR, 22 or to assess molecular similarity. 23 Direct 3D representations can be used for data sets of pre-aligned structures (e.g. relative to a reference or after docking to a receptor) or can be processed by convolutional neural networks. GUIDEMOL enables the calculation of 3D grids representing molecules based on the electrostatic potential or voxel encoding, and their parameters can be specified by the user with the graphical interface.

## The Graphical User Interface
The GUIDEMOL interface (Fig. 1 ) was built with various types of tkinter widgets controlled by its grid geometry manager (not to confuse with the 3D grid of descriptors):
• Buttons to trigger the calculations (generation of 3D structures, or calculation of descriptors).
• Checkbuttons to enable YES/NO options (e.g. include or not the calculation of a specific descriptor). • Radiobuttons to enable choices among mutually exclusive options (e.g. the atomic property for a voxel 3D grid). • Entries to submit numbers (e.g. coordinates of a 3D grid).
• Labels to display text (e.g. before Entry areas).
• Scrollbar.
The generation of 3D structures and the calculation of descriptors start with native look-and-feel dialog windows for file/directory selection, which are implemented with the tkinter.filedialog module. Users can thus choose the input and output files. A log file is created in the same directory to register the successful processing of each molecule, as well as failures.

## Generation of 3D structures from SMILES
The 3D molecular models are obtained with the RDKit function MMFFOptimizeMolecule and the arguments mmffVariant='MMFF94' and maxIters=5000. Several options are available previous to the generation of the models: to remove metals (based on the MetalDisconnector class), to keep the largest fragment (uses LargestFragmentChooser(preferOrganic=True)), or to neutralize (uses Uncharger). The hydrogen atoms are added with Chem.AddHs().

## Calculation of molecular descriptors
The interface enables the selection of several 3D descriptors that are available in the RDKit rdMolDescriptors module: RDF, MORSE, WHIM, AUTOCORR3D, GETAWAY, PEOE_VSA and SMR_VSA. a The exact molecular weight can also be chosen.
The grid of electrostatic potential is generated by the Gasteiger or MMFF partial atomic charges calculated with RDKit (AllChem.ComputeGasteigerCharges() or GetMMFFPartialCharge(), respectively). A grid is made of cubes, and the electrostatic potential EP at each cube c is obtained as a It was observed that for some molecules, and some GETAWAY, MORSE and WHIM descriptors, different values were obtained with the same RDKit version (2022.9.5) in different runs or in different operating systems. An example was with the 3D structure generated for COc1ccc(cc1(OC))Br.
EP c = ∑ i=1 N q i r ic
where q i is the partial charge at atom i, r ic is the distance between atom i and the center of cube c, and N is the number of atoms in the molecule excluding a) the atoms at a distance < 1 Å from the center of the cube (the contribution is equal to its partial charge) and b) the atoms further than the user-defined cutoff distance. The coordinates of the center of the grid, the size of each side (in Angstrom) and the size of the cube are also defined by the user.
Voxelisation of atoms is calculated in a user-defined 3D grid based on an atomic property. The final value, VoxG c , at each grid cube c is calculated as:
VoxG c = ∑ i=1 N p i ×exp ( -r ic 2 2 σ 2 )
where p i is the property of atom i, r ic is the distance between atom i and the center of cube c, σ is a parameter determining how fast the contribution of an atom decreases with the distance, and N is the number of atoms in the molecule excluding the atoms further than the cutoff distance. Implemented properties are the atomic number of the element, the partial atomic charge (Gasteiger or MMFF) and atomic contributions to molecular refractivity and logP using the Wildman-Crippen approach 24 (calculated with _CalcCrippenContribs() of the rdMolDescriptors module).
The descriptors are calculated from the 3D structure supplied by the user. However, an option is available for the addition of missing hydrogen atoms, for which the 3D coordinates are calculated without changing the coordinates of the other atoms (using AddHs() with the argument addCoords=True).
The molecular descriptors are saved in a csv output file. The last columns consist in the molecule name (the molecule name in the input file or the SMILES if no name was provided) and the molecule ID number (the position of the molecule in the input file).

## Additional command-line interface (CLI) for 3D grids
The calculation of EP and voxel grids can be obtained either via the tkinter GUI or the command-line.
The CLI uses the command

## guidemol_version.py [-h] -i I [-o O] -g {pot,vox} -p {Gasteiger,MMFF,MR,LogP,AtomicNumber} -cx CX -cy CY -cz CZ -r R -w W -sx SX -sy SY -sz SZ
with the specification of the input file, the output file (optional), the type of grid (EP or voxels), the atomic property, the xyz coordinates of the grid center, the cube size, the cutoff distance (in EP grids) or the sigma value (in voxel grids) and the size of the grid in each direction.
For example, the following command calculates an EP grid with Gasteiger charges, centered at (0,0,0), with size of each side 5 Å, a resolution of 0.5 Å and a cutoff of 3 Å for molecules in the file input.sdf and save the result in the file outfile.csv: guidemol.py -i input.sdf -g pot -p Gasteiger -cx 0 -cy 0 -cz 0 -r 0.5 -w 3 -sx 5 -sy 5 -sz 5 -o outfile.csv

## Conclusions
A GUI was developed for the calculation of molecular descriptors with the RDKit software, and 3D grid representation of molecules with electrostatic potential or voxels. The application facilitates the access to descriptors by scientists or students, and requires no programming skills. Furthermore, the 3D grid representations can also be obtained via the CLI. The source code is released with a BSD license at https://github.com/jairesdesousa/guidemol; possible bugs or limitations can thus be easily detected and fixed.

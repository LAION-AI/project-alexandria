2-adic valuation of Stirling numbers of the second kind

notation
ν 2 (S(n, k))
definition
The 2-adic valuation of Stirling numbers of the second kind
main_conjecture
The first index for which there is a constant class is m0 - 1, where 2^(m0-1) < k <= 2^m0. For m >= m0, the m-level consists of 2^(m0-2) classes, each producing a single non-constant class for the (m+1)-level.
